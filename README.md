# MySQL Database Project

Proyecto académico desarrollado para fortalecer conocimientos sobre diseño de bases de datos relacionales y consultas SQL utilizando MySQL.

## Features

- Diseño de Base de Datos Relacional
- Modelo Entidad-Relación (DER)
- Scripts DDL
- Scripts DML
- Consultas JOIN
- Funciones de agregación
- Inserción de datos de prueba

## Tecnologías

- MySQL
- SQL
- DrawSQL

## Estructura

DDL-sentencias/

DML-consultas/

Inserccion-datos/

## Objetivos

Este proyecto demuestra conocimientos en:

- Modelado de datos
- Normalización
- Relaciones entre tablas
- Consultas SQL
- Manipulación de datos

## Setup

1. Crear una base de datos en MySQL.

2. Ejecutar los scripts de DDL.

3. Ejecutar los scripts de inserción.

4. Ejecutar las consultas DML.

## Testing

Las consultas fueron ejecutadas y validadas en MySQL verificando la consistencia de los datos y el funcionamiento de las relaciones.
